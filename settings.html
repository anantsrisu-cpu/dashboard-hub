ดูหน้ารวม

1แดชบอร์ดที่จะแสดง (4 ช่อง)

ใส่ลิงก์เฉพาะช่องที่ต้องการใช้ ช่องที่ว่างจะไม่แสดงในหน้ารวม วางลิงก์แล้วระบบจะดึงชื่อหน้ามาให้เอง แก้ชื่อ ไอคอน คำอธิบาย และสีได้ตามต้องการ

2เชื่อมต่อ GitHub

กรอกครั้งเดียว ครั้งต่อไปแค่แก้รายการแล้วกดขึ้นเว็บ

ลิงก์หน้ารวมจะเป็น —

ยังไม่มี repo หรือ token ทำตาม 3 ขั้นนี้
  1. สร้าง repo แบบ Public ชื่อตามช่องด้านบน ที่ github.com/new (ไม่ต้องใส่ไฟล์อะไร)
  2. สร้าง token ที่ หน้าสร้าง Fine-grained token ช่อง Repository access เลือก Only select repositories แล้วเลือก repo นี้ จากนั้นในส่วน Permissions ให้สิทธิ์ Contents และ Pages เป็น Read and write แล้วกด Generate token
  3. คัดลอก token (ขึ้นต้นด้วย github_pat_) มาวางในช่อง Token ด้านบน

3ขึ้นเว็บ

กดปุ่มเดียว ระบบจะอัปโหลดไฟล์ เปิด GitHub Pages ให้ และรอจนเว็บอัปเดตเสร็จ

    ขึ้นเว็บเรียบร้อย

    ลิงก์ตรงของแต่ละแดชบอร์ด

    ถ้าเปิดแล้วยังเห็นของเดิม รอประมาณ 1 นาทีแล้วรีเฟรช เพราะ GitHub เก็บแคชหน้าเว็บไว้ช่วงสั้น ๆ

    token ถูกส่งตรงไปที่ api.github.com เท่านั้น และถ้าไม่ได้ติ๊ก "จำ token" จะหายไปเมื่อปิดแท็บนี้ ใครเปิดหน้านี้ได้ก็จริง แต่ถ้าไม่มี token ของคุณจะแก้อะไรบนเว็บไม่ได้
